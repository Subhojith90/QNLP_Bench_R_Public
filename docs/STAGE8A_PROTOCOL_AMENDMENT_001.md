# Protocol amendment 001: tensor-train site count

Date: 2026-07-23

The frozen protocol contains an arithmetic typo: subject, verb, object, negation,
and four modifier positions comprise **eight**, not seven, ordered input sites.
The tensor-train implementation therefore uses eight sites. No candidate grid,
selection rule, sample, outcome, or analysis is changed. This amendment was
recorded before any tensor-train result was generated.
